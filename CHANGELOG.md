# Changelog

## v1.0.0 - 2026-06-29

Flashcard Studio is ready for public portfolio review as a React + Firebase
study workspace for vocabulary, reading practice, and active recall.

### Included

- User authentication with protected study, library, profile, and settings areas.
- Personal flashcard library with categories, search, imports, and bulk actions.
- Five study modes: flashcards, multiple choice, fill-in-the-blanks, matching,
  and crossword-style fill-in puzzles.
- Built-in SAT, PTE Academic, and TOEFL iBT vocabulary packs.
- Reading workspace with article import, progress tracking, notes, dictionary
  lookup, and save-to-flashcards flow.
- Pronunciation support through browser text-to-speech controls.
- Progress feedback through streaks, XP, achievements, daily challenges, and
  Pomodoro focus sessions.
- Worksheet and document export support for printable practice.
- Firebase Hosting, Firestore rules, storage rules, PWA metadata, and offline
  support.
- Jest and Firebase emulator coverage for core learning logic, contexts, hooks,
  i18n, import utilities, reading services, and security rules.
